## 六、接真实后端要改哪些地方（如果以后要上云）

现在是纯 mock，接后端只需要两步：

1. **`utils/request.js`** → 把 `CONFIG.baseURL` 从 `''` 改成你的接口地址
   ```js
   baseURL: 'https://your-domain.com'   // 必须是 HTTPS + 已备案域名
   ```
   `hasBase()` 一旦为真，`auth.js` 会自动从"mock 登录"切到"真实登录接口"，页面无需改动。

2. **`app.js`** → `mock: true` 保持（它只控制演示态提示），真正的分流在 request 层。

⚠️ 微信硬性要求：**必须是 HTTPS，且域名已 ICP 备案**（裸 IP 不行）。这是上云唯一的前置卡点，比写代码难得多。
