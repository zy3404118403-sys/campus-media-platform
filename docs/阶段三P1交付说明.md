## 三、过程重大坑（全部固化）

1. **🐞 文件截断事故**：python `io.open(p,'w')` 改写 db.js 时 write 抛异常 → 文件被截断为 **0 字节**（且 `node --check` 对空文件也通过，掩盖事故）。从云端 SFTP 恢复（此前 32 文件零漂移验证是关键）。**铁律：大段改写必须用 Write/Edit 工具；python 'w' 模式必须先写临时文件再 os.replace**
2. **FTS5 external content 陷阱**：写 content 表不自动更新索引（官方要求触发器内同时写 FTS 表）——首版 11/17 暴露，改自持索引+触发器双写
3. **trigram 最小 3 字符**：2 字中文词（素材/毕业/活动）极常见，必须 LIKE 双轨兜底；多词混短 token 用内存过滤
4. 部署漂移检查预期值过期（用了批八哈希，实际云端已是 HTTPS 批）→ 改**锚点式**检查（云端快照 + 内容锚点），快照存 `work/.baseline/` 供回滚
