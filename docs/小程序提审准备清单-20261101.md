## 三、合法域名（唯一的硬卡点）

### 3.1 为什么卡

小程序 `wx.request` 要求 **HTTPS + 已备案域名 + 有效 CA 证书 + 443 端口**，明确**不接受 IP、不接受自签证书**。当前平台是 `https://your-domain.example`（自签 CA），因此：

- **开发/体验版**：可在开发者工具勾选「不校验合法域名」先联调（本项目现在还没发请求，用本地 mock，所以无影响）
- **正式版**：绕不过，必须换域名

### 3.2 需要谁配合

| 步骤 | 负责方 | 产出 |
|---|---|---|
| 1 | 校方信息中心 | 分配二级域名（如 `media.xxx.edu.cn`）并加 A 记录指向服务器 |
| 2 | 服务器运维 | nginx 增 `server_name`，配置**正式证书**替换自签（`C:\nginx\conf\nginx.conf`） |
| 3 | 小程序后台 | 「开发设置 → 服务器域名」配置 **request / uploadFile / downloadFile** 三类白名单 |
| 4 | 代码 | `utils/request.js` 填 `CONFIG.baseURL = 'https://<域名>'`，页面数据源从 `mock` 切到 `request` |

> 高校 `.edu.cn` 域名通常已有主体备案，派生二级域名多数情况可直接使用——这是最快路径。**需由信息中心确认该二级域名是否已在备案范围内。**

## 四、隐私保护指引文案（可直接粘贴到后台）

路径：**小程序后台 → 设置 → 服务内容声明 → 用户隐私保护指引**

### 4.1 收集的信息与用途

| 信息类型 | 收集目的 | 使用场景 |
|---|---|---|
| 学号 | 校内在校身份核验 | 登录、区分学生/管理员权限 |
| 密码 | 账号鉴权 | 登录（服务端仅存 scrypt 加盐哈希，不存明文） |
| 昵称、头像 | 个人主页与内容署名 | 我的页面、投稿与评论展示 |
| 学号所属学院、年级 | 内容归属与推荐 | 素材按学院归类、"同学院推荐" |
| 下载记录（素材、时间、IP） | 版权溯源与授权留痕 | 素材下载时的使用规范确认留痕 |
| 投稿内容（作品、说明） | 内容审核与归档 | 投稿审核、审核通过后归档进素材库 |
| **相册 / 相机（选择上传文件）** | 选取待投稿的照片与视频 | 上传素材页调用 `wx.chooseMedia`（含拍摄） |
| 设备与日志信息（IP、UA） | 安全审计 | 异常登录排查、操作审计 |

### 4.2 第三方共享

不向任何第三方共享个人信息。素材文件存放于学校自有服务器（后续可能启用对象存储，仍为学校账号下的自有资源）。

### 4.3 用户权利

用户可在「我的」页面查看本人的收藏、下载与投稿记录；可联系融媒体中心申请更正或删除个人信息；注销账号请联系中心管理员。

### 4.4 存储与保护

数据存储于学校管理的服务器，采用加盐哈希存储密码、Cookie/令牌鉴权、操作审计日志等措施。保存期限为账号存续期间，注销后按学校数据管理规定处理。

### 4.5 联系方式

云洲大学党委宣传部融媒体中心（请在后台填写实际联系电话与邮箱）。

```

学生账号：20260000001   密码：（通过安全渠道提供，勿写在公开文档）

【功能说明】
本小程序为芜宇乐的融媒体中心内部素材管理与协作工具，仅供校内师生使用。
1. 素材库：按类型/关键词检索校内影像素材（视频、图片），查看详情、收藏、下载。

素材、专题、活动、任务列表均支持游客浏览；登录后才有收藏/下载/报名/投稿等写入能力。
```

## 九、一句话结论

**技术上已经具备提审条件（21 页可跑、图标齐、包体小、无隐私违规），真正卡住的只有两件事：**

1. **已备案域名 + 正式证书**（行政流程，需信息中心配合）
2. **真实内容填充**（现在 mock 数据量太少，审核容易判「内容空洞」）

第 2 项即使域名没到也能先做——把真实照片和真实活动/任务填进去，页面立刻有分量。
