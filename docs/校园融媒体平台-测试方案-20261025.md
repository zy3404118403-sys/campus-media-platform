## 一、判定标准总则

| 结论 | 含义 | 处理 |
|---|---|---|
| P0 致命 | 核心功能不可用 / 数据丢失 / 安全漏洞 / 全站白屏 | 立即修复，当轮必须闭环 |
| P1 严重 | 主要功能异常但有绕行方案 / 明显体验缺陷 | 当轮修复或给出明确排期 |
| P2 一般 | 次要功能/样式/文案问题，不影响主流程 | 下批统一处理 |
