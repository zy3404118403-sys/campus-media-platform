1. **从上往下走，不要跳**：后面的项依赖前面的状态（例如先登录，才能测收藏）。

4. 标 🔴 的项 —— **那是我在模拟器里测不到、必须真机确认的**，优先做。
5. 全流程约 **25–35 分钟**（不含上传大文件）。

### 0.2 更省事的入口：「设备自检」页（2026-11-02 新增）

我无法直连你的 iPad：开发者工具的真机调试要先扫码建立调试会话，而它的自动化通道只驱动**模拟器**（官方 `miniprogram-automator` 不支持真机）。所以改成**让真机自己把数据报出来**。

**用法（约 3 分钟）**：

1. 用 iPad 的微信扫 `audit/phase2/preview-qr-diagnose.png` 这张二维码
2. 打开后直接落在「设备自检」页，它会**自动测出**：
   - 机型 / 系统 / 微信版本 / 基础库 / DPR / 状态栏高度 / **底部安全区**
   - **底栏实测高 vs 占位高 vs 间隙**（对应 G-03，不用你目测）
   - 触控目标尺寸（≥44px 判定，对应 H 组）
3. 再手动做三件事（页面里有按钮）：
   - **点底部输入框** → 自动判定键盘是否遮挡（对应 G-01/G-02）
   - **点「我来选一张照片试试」** → 自动判定原生相册能否拉起（对应 F-01）
   - **点「生成 100 行压力列表」** → 记一次渲染耗时，然后快速滑动看是否掉帧（对应 H-01）
4. 点底部 **「复制报告」** → 直接粘贴发我

> 二维码有效期通常几十分钟，过期了跟我说一声，我重新生成一张。
